# Googleカレンダー自動登録

## 概要

自然な文章からGoogleカレンダーへ予定登録を行うプロトタイプです。

例：

- 明日12時から菅野さんと打ち合わせ
- 明後日10時からABC病院でLED提案
- 6月15日14時から会議

上記のような文章を入力し、確認後にGoogleカレンダーへ登録できます。

---

## 開発目的

営業活動中の予定登録を簡単にするために開発。

スマートフォンから素早く予定を入力し、
Googleカレンダーへ反映することを目的としています。

---

## 主な機能

- 予定文入力
- 内容確認画面
- Googleカレンダー登録
- iPhone音声入力対応（プロトタイプ）

## 使用技術
